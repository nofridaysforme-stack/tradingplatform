Ruled, not carded
Blocks are separated by hairline rules and whitespace, like a worked course page. No shadows, no rounded tiles. Prices are right-aligned in Plex tabular figures; dense tables use Plex Sans Condensed.
The ring carries the boldness
Eight segments in the document's order, starting at 12 o'clock and going clockwise. Filled = fired, outline = not fired, dashed violet = provisional. Everything else stays graphite.
Token refinements
Short amber #C27A00 is 3.0:1 on Ledger, so it stays for fills; amber text uses #975C00 (5.1:1). Dark theme lifts cobalt to #7FA6EE and amber to #E0A341 for AA.
